# Kira

Assistente de voz para Windows (Gemini + LiveKit): fala com você, abre painéis, toca música, controla o PC,
responde o WhatsApp, aparece na TV e no celular.

**Instalação pelo Claude Code:** abra esta pasta no VS Code e peça ao Claude Code "instala a Kira" (ele segue o [CLAUDE.md](CLAUDE.md)).

**Instalação manual:** leia [INSTALACAO.md](INSTALACAO.md) e rode `INSTALAR.bat`.

Este repositório não traz nenhum dado pessoal: cada pessoa coloca as próprias chaves no `.env` e conecta as
próprias contas.
